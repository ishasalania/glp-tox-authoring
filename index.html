02 / Execution model

Not everything needs an agent.

Deterministic operations stay deterministic. Models handle bounded language tasks; the workflow enforces limits, evidence and approvals.

Deterministic tools

Copy. Check. Transform.

Preserve fixed text; inject approved facts; evaluate explicit conditions; add deterministic verbatim copying; transform in-scope tables; assemble Word.

  • Exact-copy and numeric checks
  • Reviewed template compiler
  • Judgment-based Results tables stay author-only

Foundry agents

Write. Compare. Explain.

A writer drafts from selected evidence and approved sections. A judge returns evidence-backed findings on ambiguous comparisons and draft support.

  • Structured, sentence-level citations
  • Bounded context and call budgets
  • A judge cannot override failed checks

Human review

Confirm. Resolve. Approve.

The study director confirms facts, resolves uncertain sources and approves sections. Manual items remain visible instead of becoming invented content.

  • Study and section checkpoints
  • Explicit exception queue
  • Signing stays in the document system

Template compiler — colours become reviewed instructions
Compile the Word template into typed blocks and an approved section plan. Preserve font colours separately from highlights and apply approved, task-specific overrides: for Summary, follow the red instructions and ignore the green highlighting. Whether to delete the green markers from the output remains open. Other conflicts, theme colours and unknown styles require review, never nearest-colour guessing. Move toward explicit Word styles or content controls. Keep customer-specific plans in an approved private repository.
Evidence and validation — fail closed, not silently
Classify files and tables before retrieving evidence; uncertain classifications require review. Carry source IDs, physical pages and available grounding through each step. Azure AI Search stores page-level evidence for fallback retrieval and author questions; deterministic locate rules remain primary. Content Understanding is the main extraction route; Document Intelligence Layout is a comparison and optional second engine, with the same evidence and review requirements. Validate verbatim text, numeric values and citation presence in code; semantic support still requires model and human review. Pin supported model versions, version prompts and record run configuration. Model-specific settings must be checked rather than assuming every model supports temperature controls.
Review experience — Word first, add-in later
Start with an editable Word review copy and source manifest. A proposed Office.js add-in can later expose source inspection, section regeneration and approval through an authenticated API on Container Apps behind API Management. Tracked-change reruns require explicit implementation and validation; they are not an existing feature.
Design principle — evidence first
The solution addresses the GLP toxicology authoring workflow through reviewed template contracts, approved evidence, deterministic tools and bounded AI drafting. Validation and Word preservation remain code-enforced. Cloud orchestration, reviewer access and expanded task coverage require implementation and acceptance testing.

Acceptance measures and governance
Agree thresholds for verbatim fidelity, numeric accuracy, groundedness, task completeness, latency, cost and human review effort. Keep finalized reports as held-out comparison references, never generation inputs. Evaluations support quality evidence but do not confer GxP, CSV/CSA or 21 CFR compliance. Retention, immutable-storage scope, access controls and electronic-record requirements need quality-team approval.
Deployment decisions still to confirm
Sweden Central is the preferred region, subject to model, extraction-service and hosted-agent availability, quota and data-residency review. No US Data Zone deployment is assumed. Confirm an authorized sandbox subscription before provisioning. Private endpoints, managed identity, Key Vault and approved retention are target controls, not deployed guarantees. An eight-week delivery window is a planning hypothesis, not a commitment.
